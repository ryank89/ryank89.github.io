    How these hints work

    Event rules come live from Ninja Kiwi's public Open Data service. The tower picks are checked against PopCheck's own data, so you only see towers this week's rules allow and that can actually damage the boss or pop the bloon. Prices use the event's difficulty.

    About the data

    How the checks work. Each result is read from the tower's in-game attack data for that exact crosspath: its damage types, its Camo detection, and which bloon types its attacks are allowed to hit. Limited means it only works through an ability, splash from other pops, help from a nearby tower, or by stripping a property first.

    Game version. Built from the v56.0 game files with the v57.0 balance changes (8 Oct 2026) applied. All 18 heroes are covered at every level, plus Dan D'Monke's Masqued Macaque form. Not yet covered: the new Sniper Paragon, Monkey Knowledge, Geraldo's shop items, Sun Temple sacrifices, and boss-specific rules.
